# 관리 창 (Tkinter 데스크톱)

운영 상태·주문 진행·오류 원인을 한 창에서 보고, 신규 매수를 멈추는 창입니다. **브라우저·서버·추가 설치 없음**(Python 표준 tkinter).
키움 API를 부르지 않고 주문하지 않으며, 관리자·실행기를 띄우거나 끄지 않습니다. 창을 닫아도 관리자와 실행기는 그대로 돕니다.

## 실행

`scripts\run_dashboard.bat` 더블클릭(콘솔 없이 창만 — `pythonw`), 또는 PowerShell에서

```powershell
python -m dashboard.desktop
```

시작에 실패하면 오류 창이 뜹니다. 화면 갱신 중 오류는 창을 닫지 않고 상단에 표시하고 `logs\dashboard_error.log`에 남깁니다(비밀값 가림).

검증 환경: Python 3.12.3 · Tk 8.6(Linux, Xvfb 화면), Python 3.14.0rc2 · Tk 8.6(Linux). 자료 계층 시험은 Python 3.11에서도.
**사용자 PC(Windows, Python 3.14.4)는 미실측** — python.org 설치본에는 tkinter가 포함됩니다. 창이 안 뜨면 `python -m dashboard.desktop`
출력을 보내주세요.

표의 행을 두 번 누르면 잘린 내용 전체가 보입니다.

## 조작

| 기능 | 동작 |
|---|---|
| 5초마다 자동 갱신 | 저장된 기록을 다시 읽음(기본 켬). 끄면 일시정지 |
| 지금 새로고침 | 같은 읽기를 한 번 |
| 신규 매수 중단 요청… | 확인 대화상자 → 요청 파일을 **없을 때만** 만듦(반복 눌러도 하나). 실행기가 다음 폴링(최대 약 60초)에 반영하면 '반영됨'. 매도·손절·미해결 주문 확인은 계속. 자동 재개 없음 |
| 재개 | 창에 없음 — PowerShell에서 `python tools/buy_halt.py resume --note "확인 내용" --confirm` |
| 로그·운영 요약 저장… | 날짜 입력 → 저장 위치 선택 → zip(비밀값 가림, .env·DB 원본 제외) |
| 실행 명령 보기 | 관리자·실행기·중단·원장 명령을 복사 버튼과 함께 표시(창에서 실행하지 않음) |

첫 버전에 없는 것: 직접 매수·매도, 프로세스 종료, 원장 정정, 설정 편집.

## 안전 원칙

- SQLite는 `mode=ro`로만 엶(만들기·스키마 변경·쓰기 없음). 원장도 줄 단위로 읽기만.
- 잠금·일시 충돌은 짧게 다시 읽고, 계속되면 '잠금'으로 표시. 관리자·실행기의 잠금 파일은 잡지 않음 — 실행 여부는 heartbeat로만 판단.
- 창이 쓰는 파일: 신규 매수 중단 요청, (화면 오류가 났을 때만) `logs/dashboard_error.log`, 사용자가 고른 위치의 요약 zip.
- 비밀값: 설정의 앱키·시크릿·계좌번호·카카오 토큰과 일반 비밀값 형태를 화면·저장 파일에서 가림.

## 적용 순서

실행기에 상태 파일·중단 처리 코드가 들어가므로, 작업 스케줄러 실행기(`app.main`)가 돌고 있으면 멈춘 뒤 적용하고 다시 시작합니다.
관리자 코드는 바뀌지 않아 재기동이 필요 없습니다. 실행기가 새 코드로 한 번 돌기 전까지 창의 실행기 칸은 '파일 없음'입니다.
