## 1. 관찰 확대 기준 (먼저 고정 — 과거 신호 수로 고르지 않음)

| 항목 | 값 |
|---|---|
| 최종 총수 | **25종목** = 기존 5 + 추가 20 |
| 추가 구성 | KOSPI 15 + KOSDAQ 5 (`suggest --kospi 15 --kosdaq 5` — 기존을 뺀 **추가** 수) |
| 기준 | 최신 종목 목록 스냅숏, 보통주, 수집 대상, 지금 진입 자격 있음, 위험 표시 없음, **시가총액(상장주식수 × 현재가) 큰 순** |
| 제외 | 이미 등록된 종목, ETF·ETN·리츠·우선주 |
| 하지 않음 | 과거 S1 신호 수·수익으로 종목 고르기, 목록을 본 뒤 기준 바꾸기 |

`suggest` 출력 끝에 "기존 N + 추가 후보 M = 총 T"가 나옵니다.

## 2. 빈도 분석 보완 (`tools/s1_frequency.py`)

```powershell
python tools/s1_frequency.py --days 250 --group base5=005930,005380,010120,058470,196170 --group all25=watch --recent-from 2026-07-01
```
- **0장 그룹·기간 비교**: 그룹 × (전체 / 최근) — 거래일, 분석 표본, 데이터 준비, 패턴 PASS, 종목·날짜 신호, 신호 날, 신호 종목, 7일 묶음(탐색용), 가장 긴 무신호(진행 중 표시).
- **눌림 실패 세부 사유**: 기간 범위 밖·고점이 전날·더 낮은 종가 없음·60일선 이탈·60일선 판정 불가·데이터 부족(사유).
- **월별(그룹별)**: 분석 표본, 데이터 준비, 데이터 보류(사유별), 패턴 PASS, 최종 PASS, 신호 날 수.
- 탈락 조건은 겹침 — 순위만으로 완화 효과를 판단하지 않는다는 문구.
- 용어: 종목·날짜 신호 수 / 7일 묶음(탐색용) / 운영 규칙 적용 진입 수(결과 측정 도구 순차 결과). 종목 수 비례 추정은 쓰지 않음.
- CSV 가격 열 이름 `base_stop_ref`·`base_entry_cap`·`base_pullback_days` — BASE 전용(변형별 값 아님).
- 결과 파일: `_<실행 ID>` 고유 이름·배타적 생성(덮어쓰기 없음).

## 3. 신호 결과 측정 (`tools/s1_outcome.py`) — 연구용 일봉 근사, 운영 체결 재현 아님

```powershell
python tools/s1_outcome.py --days 250                    # 관심·S1 종목
python tools/s1_outcome.py --codes 005930 --exit-slip-bps 20
```

| 단계 | 처리 |
|---|---|
| 진입 | 신호 다음 거래일 **시가 진입 가정**. 시가 > 지정가(상한 호가 내림) → 미진입(장중 저가가 내려와도 체결로 안 봄). 시가 ≤ 손절 기준 → 미진입. 봉 없음·거래정지 → 판정 불가 |
| 갭 손절 | 둘째 날부터 시가 ≤ 손절가 → 시가 × (1 − 청산 슬리피지) |
| 장중 손절 | 저가 ≤ 손절가 → 손절가 × (1 − 슬리피지) |
| 진입일 손절 | 선후 불명 → **불확실 표본**, 보수적으로 손절 처리 |
| 시간 청산 | 진입일 0일 → 10번째 거래일. 운영은 15:10 시장가, 여기서는 **종가 근사**. 같은 날 손절 조건이면 손절 먼저 |
| 거래량 0 봉 | 거래 없는 날로 건너뜀(거래정지 확정 아님), 확정 표본에 포함 — 건수 표시 (G1) |
| 봉 없는 세션(그 종목 첫 봉~마지막 봉 사이) | 원인 불명 공백 → `DATA_GAP_UNCERTAIN`, **확정 손익 통계에서 제외** (G1 — 이전엔 건너뛰고 포함) |
| 마지막 봉 이후 | 데이터 끝(공백 아님) |
| 진입일 | 봉 없음 `ENTRY_DATA_GAP` · 거래량 0 `ENTRY_NO_TRADES` (이전엔 `ENTRY_NO_DATA` 하나) |
| 끝까지 미청산 | OPEN_AT_END — 손익 통계에서 제외 |
| 비용 | 운영 추정(수수료 0.35%·매도세 0.20%, 원 단위 올림), 1주, 가격 원 단위 반올림. 비용 차감 전·후 함께. 슬리피지 기본 진입 0bp(지정가 넘지 않음)·청산 10bp |

출력:
- 신호 → 진입 가정 성립 → 청산 완료 → 미청산
- 진입 상태별 건수
- 신호별 독립 결과와 순차 계좌(최대 1포지션) 결과: 평균(비용 전·후), 중앙값, 승률, 평균 이익·손실, 최대 연속 손실, 청산 사유별 건수, 불확실 표본 수
- 순차 선택 거래 수익률의 단순 합·그 합산선의 하락 — **계좌 수익률·계좌 낙폭이 아님**(참고용)
- 가상계좌(G1, H2에서 이름 정리 — **실제 운영 재현 아님**: 주문 허용 종목·실제 진입 시간·안전 한도·일일 중단을 재현하지 않으며 1주는 수량만 맞춘 것): 초기 자금 `--capital`(기본 1,000만 원), 현금·보유 평가액(그날 종가)·비용 반영 일별 평가 곡선. 1주 고정(운영과 같은 수량)과 고정 금액 `--per-trade`(기본 자금 전액, 비용 포함 현금 한도로 수량 줄임)를 함께 냄. 계좌 수익률·계좌 최대 낙폭(%·원)·최대 투입 비중·보유일 비율·비용 합·건너뛴 거래
- 진입 시 손절 거리(G1): 진입가 기준 `(진입 − 손절 기준)/진입`, 상한 기준은 따로(`stop_dist_cap_pct` — 운영 risk_ratio_at_cap과 같은 기준). 구간(5·8·12%)별 표본·평균·중앙값·최악·승률·큰 이익(+15% 이상), 상한(≤5·8·10·12·15%)별 남는 신호·통계·큰 이익 남음. 측정용 — 운영 조건 아님
- 데이터 품질: 공백 불확실 거래 목록, 거래 없는 봉을 건너뛴 거래 수
- 순차 거래 목록

순차 계좌 규칙:
- 진입일에 보유가 없을 때만 진입(이전 청산일 < 진입일).
- 같은 진입일 후보는 종목코드 순으로, 진입 가정이 성립하는 첫 신호.
- 신호마다 한 번만.
- 일일 손실 한도는 반영하지 않음.

한계: 지금 저장된 수정주가와 최근 종목 목록을 씁니다. 과거 시점의 종목 자격이나 상장폐지 종목(생존편향)은 재현하지 못합니다.

## 5. 빈도 분석 데이터 보류 사유 (G1)

이력 창(160세션) 검사 실패를 원인별로 나눕니다. 이전에는 모두 `SHORT_HISTORY`였습니다.

| data_status | 뜻 |
|---|---|
| `SHORT_HISTORY` | 첫 봉 이전 세션이 창에 걸림(상장·수집 시작이 늦음 — 진짜 이력 부족) |
| `DATA_GAP_IN_WINDOW` | 첫 봉 이후인데 봉이 없는 세션(수집 누락 등 원인 불명) |
| `NO_TRADES_IN_WINDOW` | 창 안에 거래량 0 봉(거래정지 가능성 — 확정 아님). 그 봉이 창에서 빠질 때까지 160세션 동안 보류 |
| `SHORT_SESSIONS` | 분석 세션 목록 자체가 짧음 |

보고서 4장에 종목별 보류 사유와 "4-1. 종목별 일봉 품질"(첫·마지막 봉, 중간 공백 세션, 거래 없는 봉)을 냅니다. 운영 S1의 판정 기준은 바꾸지 않았습니다.
