# H1 — 주문 미허용 승인 후보의 장초반 가격 관찰

배경(GPT 10/27 ③): 실행기는 주문 허용 종목(`swing_strategy.allowed_symbols`, 현재 005930) 밖의 승인 후보를 `NOT_ALLOWED`로 건너뛰고 가격을 보지 않습니다. 관찰을 25종목으로 넓혀도 그 후보들이 09:05~09:30에 실제 진입 조건을 만족했는지는 기록되지 않았습니다. 일봉 시가 진입 가정(`s1_outcome`)과 실제 운영 시간대의 차이를 줄이기 위한 자료입니다.

## 동작

| 항목 | 내용 |
|---|---|
| 대상 | 그 폴링의 승인 후보(READY) 중 주문 허용 종목이 아닌 것. 허용 종목 제한이 없으면(그림자) 관찰 없음 |
| 시간 | 진입 시간(entry_start 09:05 ≤ 지금 < entry_cancel_at 09:30), 정규장 |
| 순서 | (H2) 실행기가 그 폴링의 주문 의도를 **모두 처리·전송한 뒤** `after_tick`에서 관찰 — 주문 의도 반환 경로와 분리. 보유·미해결 주문이 있어도 계속 |
| 판정 | 주문 직전 재확인과 같은 기준(`entry_reasons`): 현재가 > 손절 기준, 현재가 ≤ 진입 상한, 최우선 매도호가 ≤ 지정가 |
| 조회 한도 | 종목당 55초 간격(폴링 60초마다 한 번), 한 폴링 최대 5종목(오래 안 본 종목부터), (H2) 한 폴링 전체 15초 예산, 진입 마감 뒤 조회 안 함 |
| 시각 | (H2) 종목마다 요청 시작(`requested_at`)·응답 수신(`received_at`)을 실행기 실제 시계로. 마감 뒤 받은 값은 `in_window=false` — 최초 충족·충족 횟수에 안 셈 |
| 분리 | 주문 의도 없음, **신호 키를 읽거나 쓰지 않음** — 나중에 허용 종목이 바뀌어도 그 신호가 막히지 않음 |
| 실패 | 조회 예외 → `QUOTE_FAILED` 기록. 기록 파일 쓰기 실패는 삼킴. 매매에 영향 없음 |

## 기록 — `data/entry_observation.jsonl` (append-only)

- `OBS_QUOTE`: at(=received_at) · requested_at · received_at · in_window · trade_date · symbol · signal_id · signal_date · price · ask · limit · stop_ref · entry_cap · ok · reasons · stop_dist_pct((현재가 − 손절 기준)/현재가) · cap_gap_pct((현재가 − 상한)/상한) · quote_ms · observe_only=true
- `OBS_FIRST_OK`: 그 신호가 처음 조건을 모두 만족한 관찰(실행기를 다시 켜면 다시 남을 수 있음 — 요약은 가장 이른 것)

## 한계

- 관찰 시각 기준 현재가·최우선 매도호가 한 번 — 체결 가능성(호가 잔량·체결 경쟁)은 알 수 없음.
- 실행기가 꺼져 있던 날은 기록 없음(자동 기동 없음 — 사용자가 직접 켬).

## H2 보완 (GPT 10/27 검토)

| 보완 | 내용 |
|---|---|
| 관찰 분리 | `S1EntryStrategy.after_tick(ctx, clock)` — 실행기 `_after_tick`이 의도 처리 뒤 호출. 예외는 경고만 |

| 관찰 시각 | 종목별 요청·수신 시각, 마감 뒤 수신은 시간 안 충족으로 세지 않음. 일일 보고서 요약에 "마감 뒤 수신 N회" |

## U2 보완 (GPT 10/27 재검토 ③)

H2의 15초 예산은 조회 **시작 전**에만 확인해서, 이미 시작한 조회가 20초 걸리면 그대로 기다렸음(다음 취소·손절 처리가 늦어질 수 있음).

- 경과 시간은 `monotonic`으로(시스템 시각 변경 영향 없음).
- 조회 하나하나를 작업 스레드에서 돌리고 **남은 예산만큼만** 기다림 → 실행기가 관찰에 쓰는 최대 시간 = 예산.
- 예산을 넘긴 조회는 기다리지 않고 `QUOTE_TIMEOUT`으로 기록, 늦게 온 값은 버림. 그 조회는 키움 HTTP 시간 제한(호출당 10초, 조회 하나 = 현재가·호가 2호출) 안에 스스로 끝나며, 끝날 때까지 다음 폴링은 관찰을 건너뜀 — 관찰 조회는 동시에 1개 이하, 폴링 간격(60초)보다 짧게 끝남.
